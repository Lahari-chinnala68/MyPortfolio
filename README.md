# 🌐 Personal Portfolio Website

## 📌 Overview

This is my **personal portfolio website** built using HTML, CSS, and JavaScript. It showcases my skills, projects, education, and contact details in a clean, modern, and responsive design.

---

## 🚀 Live Demo

👉 https://lahari-chinnala68.github.io/MyPortfolio/

---

## ✨ Features

* Smooth scrolling navigation
* Scroll-based animations (fade & slide effects)
* Typing animation in the hero section
* Responsive design (mobile-friendly 📱)
* Project cards with clickable links
* Resume view & download functionality

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and animations
* **JavaScript** – Interactivity and dynamic effects

## 🎯 Key Functionalities

### 🔹 Scroll Animation

Sections are hidden initially and appear smoothly when the user scrolls using CSS transitions and JavaScript.

### 🔹 Typing Effect

Displays text like:

```id="x3f9f6"
Full Stack Developer | Java | React
```

with a typing animation effect.

### 🔹 Resume Options

* **View Resume** → Opens resume in a new tab
* **Download Resume** → Downloads the file
